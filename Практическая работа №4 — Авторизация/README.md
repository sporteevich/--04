# Практическая работа №4. Авторизация (десктоп)

Десктопное приложение на Python + Tkinter: окно входа с проверкой логина и пароля
по хешу SHA-256, ограничением числа попыток и показом пароля.

## Файлы

| Файл | Назначение |
|---|---|
| `autorize.py` | сама программа (запускать её) |
| `Отчёт_ПР4_Авторизация.docx` | отчёт по работе: цель, листинг, скриншоты, тесты, вывод |
| `test_logic.py` | автотесты логики (21 проверка) |
| `driver.py` | снимает скриншоты реальных окон приложения в папку `screenshots/` |
| `screenshots/` | скриншоты всех состояний интерфейса |

## Запуск

```powershell
python autorize.py
```

Сторонние библиотеки не нужны: Tkinter и hashlib входят в стандартную библиотеку Python.

Демонстрационные учётные записи:

* `admin` / `1234`
* `user` / `qwerty`

## Что умеет программа

* поля «Логин» и «Пароль» (пароль скрыт звёздочками);
* чекбокс «Показать пароль»;
* кнопка «Войти» и клавиша Enter;
* проверка пустых полей;
* сверка SHA-256-хеша пароля с «базой» `USERS`;
* 3 попытки, затем сообщение «Блокировка» и закрытие приложения;
* после ошибки поле пароля очищается, курсор возвращается в него.
